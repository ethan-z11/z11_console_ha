# 更新日志

## 1.0.60

- 修复：房间「添加设备」弹窗里点灯/窗帘行的链接图标看似没反应——两个模态弹窗叠层所致，现在会先收起「添加设备」再打开绑定弹窗，绑定弹窗关闭后自动开回
- 宿主设备下拉只列出已加入房间的灯 / 窗帘（宿主没有卡片就无法打开它的设置弹窗，绑定没有意义）；「添加设备」里也只有已入房间的灯/窗帘行才显示链接图标

## 1.0.59

- 紧急修复：1.0.58 同步主仓代码时误删了 consoleClient.ts 的 apiPath（Ingress 路径前缀），导致侧边栏 Ingress 下前端 WebSocket 连不上后端、一直「正在重新连接」/ 显示演示数据

## 1.0.58

- 新功能「子设备绑定」：设置 → 自定义 → 子设备绑定（灯 / 窗帘），或在房间「添加设备」弹窗里点灯/窗帘行的链接图标直接绑定；子设备不再单独显示卡片，只在宿主卡片的设置弹窗里以大卡片展示与控制，大卡片宿主绑定子设备后也会出现设置按钮
- 子设备绑定支持手动输入实体 ID（空格 / 逗号分隔多个），勾选即自动保存，无需点保存按钮
- 子设备自动移出原房间，不进「正在运行」、不参与一键关闭

## 1.0.57

- 紧凑桌面分辨率：修复药丸文字被截断——去掉 max-height/overflow hidden，改用 white-space: nowrap 防止换行
- 紧凑桌面分辨率：hero 去掉固定 232px min-height，内容自然结束，摄像头等下方板块往上靠拢
