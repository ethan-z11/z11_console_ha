# 更新日志

## 1.1.3

- 所有设备卡片都支持长按打开设置弹窗：开关（继电器 / 插座）、灯、风扇、窗帘、电视、扫地机在大卡片下也能长按进入设置，延时关闭计时不再只在小卡片 / HomeKit 模式下可用
- 开关卡片支持绑定子设备：继电器 / 插座可绑定开关与传感器（如功率、状态传感器），绑定后集中在开关弹窗内显示与控制，不再单独成卡；绑定范围仅限 switch / sensor 类实体

## 1.1.2

- 新增匹配热水器：water_heater 域实体，以及名称含“热水器”的空调实体，使用与空调一致的卡片；不受夏季停用限制，制热提醒药丸一并计入
- 热水器支持绑定控制按钮与传感器（如零冷水开关、燃烧状态）：在“设备绑定”里选中后，集中在热水器弹窗内显示与控制，不再单独成卡

## 1.1.1

- HomeKit 卡片比例优化：2×1 大卡恢复原版方形卡片样式（电源 / 名称 / 齿轮），点击按原结构操作；只有 1×1 小卡使用 HomeKit 横排窄样式
- 房间页面与首页新增运行中设备提醒药丸：风扇、空调、开关（继电器）打开时显示，点击可查看列表并一键关闭
- 房间页面新增「正在计时」药丸：有设备倒计时时显示，点击打开全部计时列表，可逐项取消

## 1.1.0

- 全新「延时关闭」计时：灯、开关、插座、风扇、窗帘、空调、电视、扫地机等设备的设置弹窗内可开启倒计时，到时自动关闭；支持时/分滚轮选择、数字手填与常用时长快捷键；倒计时进行中显示剩余时间，可随时提前取消
- 首页新增「正在计时」药丸：显示进行中的计时数量，点开可查看全部计时设备与剩余时间，并可逐项取消
- 计时跨设备同步：任意页面（手机 / 平板 / 网页）设置的倒计时全局可见；设备被其它方式关闭时对应计时自动作废，重新打开设备也不会被旧计时误关
- 新增 HomeKit 卡片比例（设置 → 自定义 → 主页显示，仅对当前设备生效，建议移动端打开）：灯、开关、风扇、窗帘卡片变为宽扁比例，大卡片同宽两倍高；已开的灯直接显示亮度百分比（色温模式追加 K 值，彩色模式不显示）；长按卡片弹出设置
- 修复一批界面问题：弹窗保存后自动关闭、手机分辨率页头不再挤压换行、HomeKit 卡片状态完整显示不截断、天气小组件手机端位置优化、移除「账号在家」状态药丸等
- 摄像头低延迟播放优化：WebRTC 与 MSE 自动选择最优路径，网络受限时自动回退
- 子设备绑定：灯 / 窗帘可绑定子设备，在宿主卡片设置弹窗内集中查看与控制
- 主页版面自定义：同排布局（摄像头与常用设备 4:6）、卡片缩放、紧凑排版、时间 / 天气 / 电池等显示开关
- 电量管家：电池提醒药丸、低电告警、常驻电池实体、手动添加电量传感器
- 侧边栏 Ingress 访客免登录进入控制台，管理员验证 1 小时临时会话
- 沉浸模式、运动检测抓拍、天气 / 农历卡片、扫地机地图等基础功能
